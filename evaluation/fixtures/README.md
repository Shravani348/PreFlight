# Evaluation Fixtures

This directory contains **SYNTHETIC DEVELOPMENT FIXTURES** used to evaluate the PreFlight AI framework.

## Strict Anonymization and Privacy Notice

* **NO Real-World Identity Data:** These fixtures contain ZERO real-world personal identification records.
* **NO Aadhaar or PAN Numbers:** All numbers are synthetically generated mock samples.
* **NO Real Documents:** All textual payloads and metadata are synthetic approximations designed to test pipeline logic.

## Directory Structure

* `classification/`: Synthetic test cases for document classification.
* `matching/`: Synthetic test pairs for name, date of birth, and address comparison.
* `instructions/`: Synthetic guideline statements for requirement parsing.
* `extraction/`: Synthetic test documents for structured field extraction.

## Notice on Dataset Type

> **DEVELOPMENT / SYNTHETIC EVALUATION DATA**
> These fixtures validate framework plumbing, metric computation, and deterministic baselines.
> They do **NOT** represent production accuracy on messy real-world government documents.
